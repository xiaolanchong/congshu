1️⃣

Կողպա ելան սելերը

Կողպա → «замок», «запор»
ելան → «вышли», «поднялись», «раскрылись»
սելերը → «сёдла / упряжь / ремни (седельные части)»

👉 буквально:
«Замки (запоры) упряжи раскрылись»
(то есть всё “развязалось, разошлось”)

2️⃣

Կտրան հոգուս թելերը

Կտրան → «перерезались», «оборвались»
հոգուս → «моей души»
թելերը → «нити»

👉
«Нити моей души оборвались»

3️⃣

Կամա՛ց քշեք սելերը

Կամաց → «медленно», «потише»
քշեք → «гоните» (лошадей)
սելերը → «повозки / упряжь / седла» (по контексту — движение с лошадьми)

👉
«Медленнее гоните (лошадей/повозку)»

4️⃣

Կապեմ չուլքուս թելերը

Կապեմ → «я завяжу»
չուլքուս → «моего чулка / мешка / поклажи» (диалектное; в песнях часто — часть упряжи или одежды)
թելերը → «нити, завязки»

👉
«Дай завяжу нитки (ремешки) своей поклажи/снаряжения»

5️⃣

Ալ էղնիմ, ալ էղնիմ

Ալ → «ещё / снова / вот бы» (здесь — желание)
էղնիմ → «стану / буду»

👉
«Ах, если бы я стал, если бы стал»

6️⃣

Դոշիդ վրա խալ էղնիմ

Դոշիդ վրա → «на твоей груди»
խալ → «родинка»
էղնիմ → «стал бы»

👉
«Стал бы родинкой на твоей груди»

7️⃣

Թուշդ պագնեմ զօր-գիշեր

Թուշդ → «твои щёки»
պագնեմ → «буду целовать»
զօր-գիշեր → «день и ночь»

👉
«Твои щёки буду целовать день и ночь»

8️⃣

Ես քո սիրած յարոն եմ

Ես → «я»
քո սիրած → «тобой любимый»
յարոն → «возлюбленный» (ласкательное, народное)
եմ → «есть»

👉
«Я твой любимый (возлюбленный)»

9️⃣

Աղջի՛, գնանք մեր բախչեն

Աղջի՛ → «девушка!» (обращение)
գնանք → «пойдём»
մեր → «наш»
բախչեն → «сад» (тюрк. заимствование, народное)

👉
«Девушка, пойдём в наш сад»

🔟

Բանանք մեր սրտի բոխչեն

Բանանք → «откроем»
մեր սրտի → «нашего сердца»
բոխչեն → «узелок, свёрток»

👉
«Откроем узелок нашего сердца»
(метафора: раскроем чувства)

1️⃣1️⃣

Պագըմ դու տուր, պագըմ՝ ես

Պագըմ → «поцелуй»
դու տուր → «ты дай»
ես → «я»

👉
«Ты дай поцелуй — и я (дам)»

1️⃣2️⃣

Թող դուշմաններն ամաչեն

Թող → «пусть»
դուշմաններն → «враги»
ամաչեն → «постыдятся»

👉
«Пусть враги постыдятся»
